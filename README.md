# JLPT 備考練功房

個人 JLPT 備考用 Angular 前端網站，涵蓋單詞、句型、文法、考古題與個人學習進度追蹤。

- **Framework**: Angular 20（standalone components、signals、Zoneless）
- **Styling**: Tailwind CSS v4
- **UI Library**: PrimeNG 20
- **Backend**: Firebase（Auth + Firestore）


## 環境需求

- Node `24.14.0`
- npm `10+`

## 安裝

```bash
npm install
```

## 啟動開發伺服器

```bash
npm start
```

啟動後開啟 [http://localhost:4200/](http://localhost:4200/)。

## 建置

```bash
npm run build
```
